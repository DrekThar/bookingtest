# Тестовое задание на должность PHP разработчик
Вакансия: https://spb.hh.ru/vacancy/126478282

## Требования

На сервере должны быть установлены mysql, php-8.2+, composer, node или у них должен быть доступ к контейнеру, если используется Docker

## Развертывание проекта

### 1. Клонирование репозитория в текущую директорию

```bash
git clone https://github.com/DrekThar/bookingtest.git .
```

### 2. Установка зависимостей

```bash
composer install --optimize-autoloader

npm install
```

### 3. Настройка окружения (.env)

Создайте файл конфигурации окружения `.env` из примера и сгенерируйте ключ приложения.

```bash
cp .env.dist .env

php artisan key:generate
```

После этого **отредактируйте файл `.env`**, указав корректные значения для вашего окружения:

- `APP_URL`: Полный URL сайта.
- `DB_HOST`: Адрес сервера базы данных (например, `127.0.0.1`).
- `DB_PORT`: Порт сервера базы данных (например, `3306`).
- `DB_DATABASE`: Название вашей базы данных.
- `DB_USERNAME`: Имя пользователя для подключения к БД.
- `DB_PASSWORD`: Пароль пользователя для подключения к БД.


### 4. Выполнение миграций и сидеров

Создайте структуру базы данных и заполните ее требуемыми тестовыми данными. При каждом запуске сидеров таблицы очищаются

```bash
php artisan migrate --seed --force
```

### 5. Сборка Frontend ассетов

```bash
npm run build
```

Также создайте символическую ссылку для публичного доступа к файлам в `storage/app/public`.

```bash
php artisan storage:link
```

### 6. Настройка веб-сервера (Nginx/Apache)

Настройте веб-сервер так, чтобы корневой директорией (document root) для вашего домена была папка `public` проекта.

## Запуск тестов

Заполните пустые поля в .env.testing. Можно использовать те же, что и в .env т.к. в тестах используются транзакции (DatabaseTransactions). 
Для запуска всех тестов выполните следующую команду в корневой директории:
 
```bash
 php artisan test --env=testing
```
